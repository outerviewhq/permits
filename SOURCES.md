# Sources and provenance

Outerview permit publications are assembled from public and licensed sources.
The original publisher, source dataset, source URL, license terms, geographic
boundaries, and known limitations are documented in each country repository.

Source attribution is preserved wherever practical. A source-derived sample
is published only when its license permits redistribution under the terms
documented for that country publication.

The parent repository does not claim coverage for a country until a linked
country repository provides its source and coverage documentation.
