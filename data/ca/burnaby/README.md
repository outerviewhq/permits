# Burnaby permits

Outerview permit datasets for Burnaby (CA).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Addition Permit](addition-permit.geojson) — 115 rows. Full dataset: [https://outerview.ai/data/addition-permit/burnaby](https://outerview.ai/data/addition-permit/burnaby)
- [Alteration Permit](alteration-permit.geojson) — 115 rows. Full dataset: [https://outerview.ai/data/alteration-permit/burnaby](https://outerview.ai/data/alteration-permit/burnaby)
- [Demolition Permit](demolition-permit.geojson) — 45 rows. Full dataset: [https://outerview.ai/data/demolition-permit/burnaby](https://outerview.ai/data/demolition-permit/burnaby)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
