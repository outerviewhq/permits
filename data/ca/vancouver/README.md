# Vancouver permits

Outerview permit datasets for Vancouver (CA).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

- [Commercial Permit](commercial-permit.geojson) — 294 rows. Full dataset: [https://outerview.ai/data/commercial-permit/vancouver](https://outerview.ai/data/commercial-permit/vancouver)
- [Construction Permit](construction-permit.geojson) — 1500 rows. Full dataset: [https://outerview.ai/data/construction-permit/vancouver](https://outerview.ai/data/construction-permit/vancouver)
- [Demolition Permit](demolition-permit.geojson) — 1500 rows. Full dataset: [https://outerview.ai/data/demolition-permit/vancouver](https://outerview.ai/data/demolition-permit/vancouver)
- [Door Permit](door-permit.geojson) — 62 rows. Full dataset: [https://outerview.ai/data/door-permit/vancouver](https://outerview.ai/data/door-permit/vancouver)
- [New Building Permit](new-building-permit.geojson) — 1500 rows. Full dataset: [https://outerview.ai/data/new-building-permit/vancouver](https://outerview.ai/data/new-building-permit/vancouver)
- [Pool Permit](pool-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/pool-permit/vancouver](https://outerview.ai/data/pool-permit/vancouver)
- [Temporary Structure Permit](temporary-structure-permit.geojson) — 463 rows. Full dataset: [https://outerview.ai/data/temporary-structure-permit/vancouver](https://outerview.ai/data/temporary-structure-permit/vancouver)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
