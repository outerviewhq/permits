# Harwood Heights permits

Outerview permit datasets for Harwood Heights (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Construction Permit](construction-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/construction-permit/harwood-heights](https://outerview.ai/data/construction-permit/harwood-heights)
- [Elevator Permit](elevator-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/elevator-permit/harwood-heights](https://outerview.ai/data/elevator-permit/harwood-heights)
- [New Building Permit](new-building-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/new-building-permit/harwood-heights](https://outerview.ai/data/new-building-permit/harwood-heights)
- [Residential Permit](residential-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/residential-permit/harwood-heights](https://outerview.ai/data/residential-permit/harwood-heights)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
