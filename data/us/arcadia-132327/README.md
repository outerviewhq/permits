# Arcadia permits

Outerview permit datasets for Arcadia (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Accessory Dwelling Unit Permit](accessory-dwelling-unit-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/accessory-dwelling-unit-permit/arcadia-132327](https://outerview.ai/data/accessory-dwelling-unit-permit/arcadia-132327)
- [Porch Permit](porch-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/porch-permit/arcadia-132327](https://outerview.ai/data/porch-permit/arcadia-132327)
- [Sign Permit](sign-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/sign-permit/arcadia-132327](https://outerview.ai/data/sign-permit/arcadia-132327)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
