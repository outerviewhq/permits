# Skokie permits

Outerview permit datasets for Skokie (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Alteration Permit](alteration-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/alteration-permit/skokie](https://outerview.ai/data/alteration-permit/skokie)
- [Construction Permit](construction-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/construction-permit/skokie](https://outerview.ai/data/construction-permit/skokie)
- [Electrical Permit](electrical-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/electrical-permit/skokie](https://outerview.ai/data/electrical-permit/skokie)
- [Fence Permit](fence-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/fence-permit/skokie](https://outerview.ai/data/fence-permit/skokie)
- [Garage Permit](garage-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/garage-permit/skokie](https://outerview.ai/data/garage-permit/skokie)
- [Roofing Permit](roofing-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/roofing-permit/skokie](https://outerview.ai/data/roofing-permit/skokie)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
