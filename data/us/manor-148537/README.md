# Manor permits

Outerview permit datasets for Manor (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Addition Permit](addition-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/addition-permit/manor-148537](https://outerview.ai/data/addition-permit/manor-148537)
- [Alteration Permit](alteration-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/alteration-permit/manor-148537](https://outerview.ai/data/alteration-permit/manor-148537)
- [Antenna Permit](antenna-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/antenna-permit/manor-148537](https://outerview.ai/data/antenna-permit/manor-148537)
- [Construction Permit](construction-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/construction-permit/manor-148537](https://outerview.ai/data/construction-permit/manor-148537)
- [Foundation Permit](foundation-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/foundation-permit/manor-148537](https://outerview.ai/data/foundation-permit/manor-148537)
- [Irrigation Permit](irrigation-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/irrigation-permit/manor-148537](https://outerview.ai/data/irrigation-permit/manor-148537)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
