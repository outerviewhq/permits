# Elk Grove Village permits

Outerview permit datasets for Elk Grove Village (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Construction Permit](construction-permit.geojson) — 4 rows. Full dataset: [https://outerview.ai/data/construction-permit/elk-grove-village](https://outerview.ai/data/construction-permit/elk-grove-village)
- [Demolition Permit](demolition-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/demolition-permit/elk-grove-village](https://outerview.ai/data/demolition-permit/elk-grove-village)
- [Electrical Permit](electrical-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/electrical-permit/elk-grove-village](https://outerview.ai/data/electrical-permit/elk-grove-village)
- [Elevator Permit](elevator-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/elevator-permit/elk-grove-village](https://outerview.ai/data/elevator-permit/elk-grove-village)
- [New Building Permit](new-building-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/new-building-permit/elk-grove-village](https://outerview.ai/data/new-building-permit/elk-grove-village)
- [Sign Permit](sign-permit.geojson) — 3 rows. Full dataset: [https://outerview.ai/data/sign-permit/elk-grove-village](https://outerview.ai/data/sign-permit/elk-grove-village)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
