# Monrovia permits

Outerview permit datasets for Monrovia (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Accessory Dwelling Unit Permit](accessory-dwelling-unit-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/accessory-dwelling-unit-permit/monrovia-132919](https://outerview.ai/data/accessory-dwelling-unit-permit/monrovia-132919)
- [Foundation Permit](foundation-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/foundation-permit/monrovia-132919](https://outerview.ai/data/foundation-permit/monrovia-132919)
- [Sign Permit](sign-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/sign-permit/monrovia-132919](https://outerview.ai/data/sign-permit/monrovia-132919)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
