# Pittsburgh permits

Outerview permit datasets for Pittsburgh (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Alteration Permit](alteration-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/alteration-permit/pittsburgh](https://outerview.ai/data/alteration-permit/pittsburgh)
- [Construction Permit](construction-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/construction-permit/pittsburgh](https://outerview.ai/data/construction-permit/pittsburgh)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
