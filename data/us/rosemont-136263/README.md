# Rosemont permits

Outerview permit datasets for Rosemont (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Electrical Permit](electrical-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/electrical-permit/rosemont-136263](https://outerview.ai/data/electrical-permit/rosemont-136263)
- [Roofing Permit](roofing-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/roofing-permit/rosemont-136263](https://outerview.ai/data/roofing-permit/rosemont-136263)
- [Sign Permit](sign-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/sign-permit/rosemont-136263](https://outerview.ai/data/sign-permit/rosemont-136263)
- [Structural Permit](structural-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/structural-permit/rosemont-136263](https://outerview.ai/data/structural-permit/rosemont-136263)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
