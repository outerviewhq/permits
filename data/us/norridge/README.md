# Norridge permits

Outerview permit datasets for Norridge (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Electrical Permit](electrical-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/electrical-permit/norridge](https://outerview.ai/data/electrical-permit/norridge)
- [Fence Permit](fence-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/fence-permit/norridge](https://outerview.ai/data/fence-permit/norridge)
- [Roofing Permit](roofing-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/roofing-permit/norridge](https://outerview.ai/data/roofing-permit/norridge)
- [Solar Permit](solar-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/solar-permit/norridge](https://outerview.ai/data/solar-permit/norridge)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
