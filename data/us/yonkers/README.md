# Yonkers permits

Outerview permit datasets for Yonkers (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Mechanical Permit](mechanical-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/mechanical-permit/yonkers](https://outerview.ai/data/mechanical-permit/yonkers)
- [Sign Permit](sign-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/sign-permit/yonkers](https://outerview.ai/data/sign-permit/yonkers)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
