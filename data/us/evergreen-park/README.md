# Evergreen Park permits

Outerview permit datasets for Evergreen Park (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Construction Permit](construction-permit.geojson) — 4 rows. Full dataset: [https://outerview.ai/data/construction-permit/evergreen-park](https://outerview.ai/data/construction-permit/evergreen-park)
- [Electrical Permit](electrical-permit.geojson) — 3 rows. Full dataset: [https://outerview.ai/data/electrical-permit/evergreen-park](https://outerview.ai/data/electrical-permit/evergreen-park)
- [New Building Permit](new-building-permit.geojson) — 4 rows. Full dataset: [https://outerview.ai/data/new-building-permit/evergreen-park](https://outerview.ai/data/new-building-permit/evergreen-park)
- [Roofing Permit](roofing-permit.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/roofing-permit/evergreen-park](https://outerview.ai/data/roofing-permit/evergreen-park)
- [Solar Permit](solar-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/solar-permit/evergreen-park](https://outerview.ai/data/solar-permit/evergreen-park)
- [Structural Permit](structural-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/structural-permit/evergreen-park](https://outerview.ai/data/structural-permit/evergreen-park)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
