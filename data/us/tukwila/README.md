# Tukwila permits

Outerview permit datasets for Tukwila (US).

Each GeoJSON file contains up to 1,500 records for one permit category, ordered by permit date with the newest records first.

Public feature properties include the standard permit fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Permit datasets

- [Commercial Permit](commercial-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/commercial-permit/tukwila](https://outerview.ai/data/commercial-permit/tukwila)
- [Construction Permit](construction-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/construction-permit/tukwila](https://outerview.ai/data/construction-permit/tukwila)
- [Mechanical Permit](mechanical-permit.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/mechanical-permit/tukwila](https://outerview.ai/data/mechanical-permit/tukwila)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
