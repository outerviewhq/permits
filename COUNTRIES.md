# Country repositories

This parent repository links the country-specific publications for Outerview
permit data. A country is listed here only after its repository has been
published and its coverage documentation is ready.

## Published repositories

Country-specific links will be added here as they go live.

## Repository convention

Country repositories use clear names such as:

```text
{country}-permits
```

Each country publication should explain its geographic coverage, update
frequency, source agencies, available permit types, field definitions,
licensing, and Outerview access links.
