# Outerview Permits

Open and normalized permit data from public and licensed sources.

This repository is the parent directory for Outerview permit datasets. It
explains the available permit categories and links to country-specific
repositories as coverage is published.

## Dataset overview

- Publisher: Outerview
- Category: Permits
- License: MIT
- Formats: CSV, JSON, GeoJSON, and Parquet where available
- Coverage: Country and regional coverage is documented in the linked country repositories
- Freshness: Varies by source; each country repository documents its update information

## Permit types

See the complete [permit type index](PERMIT_TYPES.md). It currently includes
54 distinct permit categories, including construction, demolition, electrical,
plumbing, roofing, solar, occupancy, and zoning permits.

## Country repositories

Country repositories are the detailed dataset publications. Each one may
contain regional pages, source notes, field details, and permitted sample data.

See [COUNTRIES.md](COUNTRIES.md) for the current publication directory.

## What can permit data answer?

- What permits were issued in a given area?
- Where is new construction occurring?
- Which permit categories are most common?
- How has permitting activity changed over time?
- Which projects have recent status changes?

## Access the full datasets

The complete, searchable Outerview datasets are available at:

- [Outerview permit datasets](https://outerview.ai/data/permits)
- [Outerview developer access](https://outerview.ai/developers)

This repository is a public discovery and documentation layer. Detailed
coverage, source attribution, and any downloadable samples belong in the
country repositories where they are available and licensed for publication.
